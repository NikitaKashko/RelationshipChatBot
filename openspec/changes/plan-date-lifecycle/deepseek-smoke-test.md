# DeepSeek smoke test, 11 октября 2026

Проверка выполнена с локальным ключом владельца; ключ и баланс в деньгах не опубликованы. Отправлялись только специально составленные тестовые запросы, без личной коллекции и переписки.

## Результаты

- GET /user/balance: HTTP 200, is_available=true.
- POST /chat/completions, deepseek-flash, thinking disabled: HTTP 200, ответ API_OK, 0.84 с. Usage: 9 input / 2 output tokens.
- POST /anthropic/v1/messages, deepseek-flash, thinking disabled, tool type web_search_20250305/name web_search: HTTP 200, 3.95 с, stop_reason=end_turn.
- Сервер вернул server_tool_use и web_search_tool_result с реальными source URLs. Это подтверждает работу native search в прямом API, без запуска Claude Code и без отдельного поискового ключа.
- Запрос просил два кафе в Москве, адреса и источники. Ответ содержал Bosco Café в Петровском пассаже и «Ладо», со ссылками на Trip.com и KudaGo. Это примеры результата, не проверенные рекомендации: независимая сверка адресов и актуальности не выполнялась.
- Тест задавал max_uses=1. Модель попыталась вызвать два web_search; результат второго содержал max_uses_exceeded. Ответ после первого результата завершился. Usage.server_tool_use.web_search_requests=2 нельзя трактовать как два успешно выполненных поиска.
- Usage поиска: input_tokens=7714, cache_read_input_tokens=384, output_tokens=481. Итоговые расходы по кабинету не сверялись. Encrypted search content не выводить и не публиковать в дальнейших диагностических отчётах; ссылки и минимальные метаданные достаточны.

## Вывод

Flash и собственный поиск DeepSeek доступны с текущим ключом. Внешний поисковый провайдер для первоначальной реализации не требуется. HTTP 200 не равен проверке всех фактов: карточки обязаны сохранять источники и отмечать непроверенные адреса/цены/часы. Фото, права на сохранение результатов и более широкое качество поиска остаются отдельными вопросами квалификации.

Тестовый max_uses ограничивал стоимость одного эксперимента; это не введение квот пользователя. Production-интеграция должна обрабатывать частичные ошибки инструментов и учитывать фактический usage без автоматических платных повторов.
