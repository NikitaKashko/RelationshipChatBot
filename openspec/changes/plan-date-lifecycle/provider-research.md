## DeepSeek расходы

На дату проверки официальная страница предлагает `deepseek-flash` (V4.1 Flash). За миллион input tokens cache-miss: $0.15 off-peak / $0.30 peak; output: $0.60 / $1.20; cache-hit: $0.003 / $0.006. Модель и тариф должны быть конфигурируемыми; прежнее имя `deepseek-chat` из прототипа нельзя считать актуальным default без проверки.

Пример расчёта без cache: 300 обращений к модели с 6000 input и 1000 output tokens каждое стоят $0.45–$0.90. Это арифметическая оценка, не обещание месячной суммы: одна просьба может породить несколько tool/summary calls, контекст растёт, search расход отдельно учитывается. Цель 500 ₽ не ограничивает расход; стоимость в рублях требует явно указанного оценочного курса, без неявного фиксированного курса.

[Официальные тарифы DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/).

## Локальная речь

Tiny и base — размеры моделей Whisper, а whisper.cpp — CPU-движок. По [официальному README](https://github.com/ggml-org/whisper.cpp#memory-usage): tiny ~273 MB RAM /75 MiB файл; base ~388 MB /142 MiB; small ~852 MB /466 MiB. Это ориентиры движка, не суммарная память сервера и не гарантированная задержка.

Текущий VPS номинально 1 CPU/768 MB RAM/7 GB SSD. Ядро планируем без Docker/Redis/PostgreSQL. Возможность одновременного ASR и бота определяется peak RSS плюс память работающего ядра и запас для ОС; отсутствие OOM на пустом сервере не подтверждает пригодность для production.

По просьбе пользователя сначала тестируем tiny и base на текущем VPS. Новый сервер не покупаем. Версия тестового whisper.cpp: v1.9.5, commit d1be6fde11ac6e0407606b4e42fe72d34add8037; [официальный release](https://github.com/ggml-org/whisper.cpp/releases/tag/v1.9.5).

Синтетический русский пример пригоден для проверки запуска и ресурсов, но недостаточен для заключения о качестве живой речи, шума и названий заведений. Для окончательного выбора нужны реальные примеры и повтор с нагрузкой ядра. Первые замеры записаны в asr-benchmark.md: tiny в быстром режиме 29.16 с/151.8 MiB RSS, base 65.23 с/242.4 MiB на 14.21 с аудио. Виртуальный CPU не имеет AVX. Реальные пользовательские аудиофайлы и тексты не публикуются в репозиторий.
