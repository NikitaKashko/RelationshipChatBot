# Эксперимент локального распознавания, 11 октября 2026

Это предварительная квалификация CPU и памяти, не приёмка качества реальной речи и не production-нагрузочный тест.

## Условия

- Debian 13 amd64, 1 vCPU, 715 MiB доступной системе RAM, swap отсутствует, бот ещё не запущен.
- Виртуальный CPU не предоставляет AVX/AVX2/FMA/F16C/SSE4.2/BMI2. Первая сборка с включёнными несовместимыми опциями завершалась SIGILL до распознавания; это исправлено CPU-совместимой сборкой.
- whisper.cpp v1.9.5, commit d1be6fde11ac6e0407606b4e42fe72d34add8037, Release, CPU-only, 1 thread.
- CMake: GGML_NATIVE/BLAS/AVX/AVX2/AVX512/FMA/F16C/BMI2/SSE42 OFF. Модели multilingual tiny/base из официально указанного ggerganov/whisper.cpp хранилища.
- Синтетическая русская запись espeak-ng, ru, 145 слов/мин, SoX → WAV mono16kHz PCM16; длительность 14.211813 секунд. Личные записи не использовались.
- Обычный режим: language ru, beam-size=5/best-of=5. Быстрый: beam-size=1/best-of=1/no-fallback. Wall time и peak RSS измерены /usr/bin/time -v для одного вызова каждого режима; не среднее нескольких запусков.

## Результаты

|---|---:|---:|---:|
| tiny, обычный | 108.40 с | 182648 KiB ≈178.4 MiB | 7.63× |
| base, обычный | 99.50 с | 290560 KiB ≈283.8 MiB | 7.00× |
| tiny, быстрый | 29.16 с | 155392 KiB ≈151.8 MiB | 2.05× |
| base, быстрый | 65.23 с | 248244 KiB ≈242.4 MiB | 4.59× |

Все четыре совместимых запуска завершились с exit code 0. После последнего теста доступно около 473 MiB RAM, новых failed systemd units нет; SSH работает. Первая SIGILL-попытка не считается успешным результатом. Запуск без OOM на пустом сервере не доказывает запас для всего продукта.

Синтетический голос распознан обеими моделями с серьёзными ошибками, в том числе в датах и бюджете. Пример фразы: «Давай завтра вечером сходим в кафе, а потом погуляем в парке. Бюджет две тысячи рублей на двоих. Перенеси свидание на пятницу, начало в семь вечера. Это место нам понравилось, но пока не предлагай его снова». Tiny и base не воспроизвели её достаточно точно для выполнения команд. Это ограничение данного синтетического примера; качество человеческого голоса по нему не измерено.

Разница обычных запусков не доказывает, что base обычно быстрее tiny: fallback/декодирование зависит от результата и количества токенов. В быстром режиме tiny быстрее на этом примере.

## Вывод и следующий тест

Tiny в быстром режиме помещается в память текущего сервера и является кандидатом для редких коротких сообщений с ожиданием. Уверенно рекомендовать его как основной ввод пока нельзя. Base на текущем CPU имеет заметную задержку; второй VPS не заказывать до проверки живой речи и совместного потребления ядра.

Нужны несколько реальных русских записей с местами, датами и шумом, замер коротких и длинных сообщений и одновременно работающего бота/панели. Имена и аудио останутся вне публичного репозитория. При покупке нового CPU важны доступность AVX2 и фактическая скорость, а не только число vCPU. Распознавание запускается очередью, без ограничений количества запросов пользователя.

Тестовые инструменты и модели сохранены на сервере для повторной проверки; постоянный ASR-сервис и новые публичные порты не созданы. Точные SSH-пути и операционные записи хранятся в локальном навыке.
