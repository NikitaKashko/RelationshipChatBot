# Подключение DeepSeek API

Проверено по официальной документации 11 октября 2026. Покупка и реквизиты выполняются самим владельцем в кабинете.

1. Зарегистрироваться или войти на [DeepSeek Platform](https://platform.deepseek.com/).
2. Открыть [пополнение баланса](https://platform.deepseek.com/top_up), выбрать доступную сумму и способ оплаты. Для первых smoke tests достаточно начать с минимальной удобной суммы; точный минимум и доступные карты подтверждаются в кабинете, не предполагаются заранее.
3. Создать отдельный ключ для проекта в [API keys](https://platform.deepseek.com/api_keys) и сохранить его локально. Не публиковать ключ в issue, документах, переписке или Git.
4. В корне проекта создать `.env` и записать `DEEPSEEK_API_KEY=ваш_ключ`. Этот файл исключён из Git. Наличие ключа не означает, что прототип уже поддерживает новый релиз или native search.
5. Для новой интеграции использовать актуальное имя модели `deepseek-flash`, OpenAI-format base URL `https://api.deepseek.com` или Anthropic-format `https://api.deepseek.com/anthropic` для проверки native search. Модель и endpoint должны задаваться конфигурацией.
6. Проверить authentication и balance, затем короткий модельный запрос, затем отдельный web-search contract test. Не выводить токен в терминал, лог или результат проверки.

API оплачивается по использованию tokens с предоплаченного или предоставленного баланса. Ошибка 401 означает проблему с ключом, 402 — недостаточный баланс. Отсутствие квот нашего приложения не отменяет правил и доступного баланса поставщика. Платный search test также может вызвать дополнительные model calls.

Ориентир проекта — 500 ₽/месяц для ИИ и поиска; это предупреждение, не автоматическая остановка. Цена в USD зависит от tokens и peak/off-peak, перевод в рубли имеет оценочный курс. Не пополнять большую сумму на основании расчёта без фактической статистики.

Источники: [первый API вызов](https://api-docs.deepseek.com/), [тарифы и списание](https://api-docs.deepseek.com/quick_start/pricing/), [ошибки authentication/balance](https://api-docs.deepseek.com/quick_start/error_codes/), [native Web Search](https://api-docs.deepseek.com/quick_start/agent_integrations/claude_code/).
